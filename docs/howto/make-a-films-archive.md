# Make a film's archive

A film needs an `.ALL` to be captured: one beside its `.FLM`, one rebuilt from the film's committed manifest under `manifests/all/` (no emulator needed), or one that `make-all` stored under `captures/<film>/archives/`. The demo ships one for `INTRO` and `CTRY` only, and it is an unpatched `MAKEONE.EXE`'s, which a film whose `references.toml` row pins `makeone = "patch3"` refuses. For a film with none of these, once:

```powershell
mise run make-all -- --film <path>.FLM
```

It takes about 90 s or more: `MAKEONE.EXE` plays the film in real time on dosbox-automation. It stores the result as the film's one archive, `captures/<film>/archives/`, where `<film>` is the film's parent folder and stem (`vault-ctry`; `--name` overrides), and `capture-ref` then checks it against the film's hash ([ADR 0023](../adr/0023-make-all-generates-archives-with-makeone.md), [`research/makeone-exe/driving.md`](../../research/makeone-exe/driving.md)).

`make-all` also writes the film's manifest, `manifests/all/<film>.toml`, for review and commit, when it can. An archive not rebuildable from the game files, or an extraction error, leaves none: `make-all` prints why, still exits 0, removes an earlier manifest of the replaced archive, and the stored archive stays the record. `--manifest-only` leaves an earlier manifest alone and exits 1 when it fails to write one, or 2 when it refuses, as for a film with no stored archive ([`make_all.py`](../../python/scripts/make_all.py), `write_manifest`). Once committed, any checkout with the game files and the build the manifest's `game_root` names (`builds/patch3`, read from the data root; [build the game builds](build-the-game-builds.md)) rebuilds the `.ALL` from it into `target/linked/` without the emulator. `mise run make-all -- --manifest-only --film <path>.FLM` writes one from an archive stored earlier ([ADR 0032](../adr/0032-a-films-archive-is-committed-as-a-manifest.md)).

When the guest has not returned to text mode within `--timeout` (600 s by default), `make-all` first saves the guest screen as `build/scratch/make-all-timeouts/<film>-<time>.png` in the data root and logs its path, then logs each process whose name contains `dosbox` (this run's among them), as `[make-all] warning:` lines on stderr, and only then judges the archive and stops the emulator. The picture is the 320 × 200 page at `A000:0000` as palette indices, in the default VGA palette's first 16 colours and grey above, not the guest's own colours: it tells a prompt or a frozen title from a scene, not a hue. If either grab fails, the failure is logged and the run ends as it would have ([`timeout_evidence.py`](../../python/stunt_reel/tac/timeout_evidence.py)). A guest that is not in mode 13h at the timeout gives a picture of whatever is at that address.
