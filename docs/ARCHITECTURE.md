## Decoding Engine and Independent Oracle

`crates/stunt-core` is the only hand-written decoder for `.RES`/`.ALL`/`.SOD`/`.FLM`, the Mode 13h palette, and decal resolution; `stunt-render`, `stunt-gltf` and `stunt-cli` consume its output. The Python package does not decode game formats. Its remaining copies of Rust knowledge live in `python/stunt_reel/tac/` (`palette.py`, `dos_math.py`, and the Seam 2 models), where the capture harness must run without a built binary; `tests/fixtures/mode13h_palette.json` and `tests/fixtures/dos_math_goldens.json` pin them to the Rust values in both languages.

The one sanctioned second decoder is deliberate: the Kaitai `.ksy` schemas under `research/formats/` and `python/stunt_reel/flm_walk.py` are written from the format description, not from the Rust code, and `python/scripts/verify_*.py` compare them against the corpus. A disagreement there is evidence about the format, so these stay independent of the Rust parsers.
