# Retro: the cloud-setup check and the lavapipe fix (2026-11-07)

Status: decisions agreed on 2026-11-07; G1-G5, G7 and G8 land in the pull request that adds this note, G6 is [#288](https://github.com/neilsh/stunt-reel/issues/288). Source: the retrospective of the 2026-11-07 session that verified the cloud setup from #263, found that lavapipe draws near ground polygons in palette index 0, and fixed it in #264. This note is the decision record and landing log, as [retro-hardening-2026-10-25.md](retro-hardening-2026-10-25.md) was for its session.

## 1. What happened

- The cloud check passed: the SessionStart hook, the R2 key pair from environment variables (unsigned request 400, signed 200) and the pinned archives all worked. Every archive was skipped as present, because the container was resumed, so a real download was proven only by deleting `corpus/stisldem` by hand.
- Lavapipe scored CTRY 0.6446 and INTRO 0.6040 against the GPU's 0.8725 and 0.8273. Per-class loss, frames, the index plane and two temporary switches led to the `linear` shade varying; a subagent pinned the Mesa clipper path ([`research/parity/lavapipe.md`](../../../research/parity/lavapipe.md)). #264 added a shader guard and a regression test that fails on lavapipe without it.
- The friction, in the order the decisions below answer it:
  1. The findings were committed to the #263 verification branch, rewritten for #264, and collided with #263's own lavapipe text, which merged mid-session.
  2. Review caught three claims broader than their evidence: the side-plane case as the only cause of the NaN, a gap "within the noise floor" where `method.md` calls 0.002 a policy bound, and all image sets "indexed". Each cost a push.
  3. 7 KB of findings went into `method.md`, already 54 KB against a guideline of about 20 KB.
  4. Eight commits and their CI and review rounds made CodeRabbit pause its reviews.
  5. CodeRabbit's generated tests landed as a commit on the PR branch, failed clippy and the commit-message check, and needed a force-push the session's permissions refused until the owner approved it.
  6. Proving an R2 download meant deleting data.
  7. A subagent's temporary shader edit in the shared checkout set off the stop hook, which asked for it to be committed and pushed.
  8. A cloud session could not attach pictures to a PR, nor reach `gitlab.freedesktop.org` for Mesa's source and issues.

## 3. Rejected

- **G2 alternatives:** a lint for absolute words (noisy, dodged by rewording), `/code-review` on every push (cost on code-only pushes), one review before the PR only (all three overclaims came in later pushes), and leaving it to CodeRabbit (a push per claim).
- **G3 as a gate check** that fails when a note over 20 KB grows: rejected for a reminder; existing large notes would need grandfathering.
- **G4 by raising CodeRabbit's pause limit:** batching removes the cause.
- **G5 alternatives:** generated tests as a separate PR, exempting bot commits from the commit-message check, or squashing them at merge. Turning the feature off removes the case.
- **G6 as `fetch --force`:** it overwrites the data root, and a failed download leaves the set missing.
