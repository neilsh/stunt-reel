# Security Policy

## Supported versions

This project is pre-alpha: only the latest `main` is supported.

## Reporting a vulnerability

Report privately through GitHub Security Advisories on this repository ("Security" →
"Report a vulnerability"). Please do not open a public issue for a vulnerability.

This project parses untrusted binary files (`.RES`, `.ALL`, `.SOD`, `.FLM`, `.SET`).
Never attach retail game data, corpus files, or any proprietary executable to a report;
a minimal synthetic reproducer is enough and preferred.

There is no bug bounty. This is a solo, pre-alpha project, so fixes are best effort.
